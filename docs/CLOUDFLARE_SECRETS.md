# Environment variables (Render)

Set these in Render → Environment (or Blueprint sync:false prompts).

## Required

- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY
- NEXT_PUBLIC_APP_URL
- OPS_APP_URL

## Recommended

- CASH_RECON_WORKER_URL
- CASH_RECON_ADMIN_KEY
- COMPANY_SUPABASE_URL
- COMPANY_SUPABASE_SERVICE_KEY
- CRON_SECRET
- EMAIL_API_KEY (or RESEND_API_KEY)
- EMAIL_FROM

See [RENDER_DEPLOY.md](./RENDER_DEPLOY.md).
